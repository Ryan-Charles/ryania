The agent that answers customer emails on its own

It reads the email, finds the order, checks the carrier’s tracking, writes a reply in the brand’s voice, and sends it. Then it archives the thread.

Description

A shop that sells in France hears the same question every day: “Where’s my order?” To answer it properly, someone has to open the inbox, find the order in Shopify, check tracking with the carrier, and write a reply they’ve already written a hundred times.

The agent follows those same steps. It finds the order, submits the tracking number to the carrier, waits for a response, reads the current status, picks the right response from about ten scenarios, and sends a reply using the brand’s templates. It takes 13 seconds for a simple case, or two and a half minutes when it needs to check with the carrier.

It also handles cancellations, refunds, delivery address changes, order quantity changes, and parcels marked as delivered that the customer never received.

The real challenge

Two mistakes an agent can make when writing to customers on your behalf: sending the same answer twice, and replying when the case needs human attention.

Before sending a reply, it checks the last six exchanges with the customer over the past 30 days, including sent and deleted messages. If the reply repeats the previous answer, even with a different date, it leaves the message unread.

For disputes, threats, chargebacks, or any case it’s unsure about, it leaves the email unread and unarchived so a person can handle it. This rule takes priority over all others.

The agent that writes, publishes, and helps Google index blog posts

Two posts a week for the store. The agent writes each one, adds internal links, metadata, structured data and an illustration, then publishes it automatically.

Description

Writing a post with a language model is easy. Maintaining a coherent SEO cluster across 50 posts takes more work. You have to avoid repeating topics, link new pages to older ones, set the right tags, generate structured data, and link each post from a page Google crawls often.

The workflow takes the next topic from a queue, loads all published posts, checks for overlap, and picks four posts to link to. It writes the article in strict JSON under twelve editorial rules, then fixes common model errors, including extra H1 headings, duplicate URL slugs, bare product links, and assistant-style sign-offs.

It generates an illustration, publishes the post on Shopify, fills in its SEO metafields, then adds a link to the pillar page, the most frequently crawled page in the cluster. That final step helps new posts get indexed faster.

The real challenge

The first version checked for identical titles. It missed closely related topics, leaving pairs of posts competing for the same searches.

The current version measures vocabulary overlap and weights it by how well the terms cover the target keyword. It ignores words that are too generic to be useful on this site and uses two thresholds, one for likely duplicates and one for confirmed duplicates.

Testing against published articles found all 8 known duplicates with zero false positives. When it detects a duplicate, it skips publication and flags the row with the score and the matching article.

The agent that runs a real estate agent’s Facebook page

It publishes an educational post on Wednesdays and showcases a listing on Sundays. The real estate agent can leave preparation and scheduling to the workflow.

Description

Posting regularly can help a real estate agent stand out locally. Finding time to make content on a Sunday morning between viewings is another matter.

On Wednesdays, the agent writes a real estate news post about France and Martinique. It switches audiences each week, writing for buyers in even-numbered weeks and sellers in odd-numbered weeks. It generates an illustration that matches the agency’s brand, with no text in the image.

On Sundays, it checks the real estate agent’s public page for live listings, selects a property it hasn’t featured before, and gathers the title, price, town, description, and photos. It writes the post and publishes a carousel, adding a video tour when one is available.

The real challenge

Two problems only became obvious once they disrupted the page.

Photos from other listings. A listing page also features a “You might like these properties” section with listings from other agents. A basic scraper can pull in their photos. This workflow keeps only images whose URL contains the current property’s ID.

Keeping track of published listings. The list of featured properties was originally stored inside the workflow and disappeared on reimport. It now lives in a dedicated table. Once every property has been featured, the workflow starts the rotation again so the page always has something to publish.

The agent that turns jobsite photos into Instagram content

It reviews the photos, chooses one, edits it if needed, writes the caption, and leaves a ready-to-review draft in Notion. The client approves and publishes it.

Demo · Production workflowNo audio
Trigger

Source

Review
Image analysis and usability check for each photo
Content plan
5 themes in rotation
Delivery
Notion draft marked “Ready”
Publishing
The client publishes after review
Description

An excavation company in French Guiana has hundreds of jobsite photos on a phone and little time to turn them into content. Its Instagram account sits idle.

Every Monday, the agent opens the client’s photo library and reviews each image. A vision model describes the scene, identifies the equipment, and decides whether the photo can be used as is. The agent then picks one of five weekly themes: mini excavator with operator, land clearing, trenches and utilities, site preparation, or fencing. It writes the caption using the language of the trade.

For the visual, it starts with the client’s original photo, then tries one edit if needed. Generating a new image is the last option. The workflow automatically crops the visual for the feed, centered on the detected subject.

Why approval stays with the client

The agent’s job is to prepare the post for the client to publish.

The draft arrives in Notion marked “Ready,” with a copyable caption and the final image. The client can review it, edit it, and publish whenever they like.

On a contractor’s Instagram page, a poorly chosen photo stands out immediately. Keeping human approval at this point matters more than posting on a perfect schedule.
